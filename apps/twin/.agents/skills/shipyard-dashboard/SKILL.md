1. 프로젝트 루트의 `docs/dashboard/README.md`에서 해당 기능을 고른다. 한 번에 선택한 기능의 명세와 해당 소스만 읽는다.
2. 필요한 경우 공통 UXML에 연결하고 동작은 기능별 런타임 코드에 둔다. 시작 시 자동 재생과 기존 조작을 보존한다.
3. 기능 완료 조건을 확인한다. Unity 테스트 또는 MCP 연결이 필요할 때만 `docs/dashboard/unity-tools.md`를 읽는다.
4. 결과에는 변경 파일, 확인한 항목, 미검증 항목만 간단히 적는다.
