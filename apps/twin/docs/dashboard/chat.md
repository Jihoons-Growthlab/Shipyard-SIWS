# 챗봇 (웹 트윈 야드 안내원)

## 화면

- 진입점은 웹 트윈(Portal `/twin/`) 화면 오른쪽 아래에 고정된 야드 안내원 캐릭터다. 상세 카드·그리드·수심 범례를 열고 닫아도 자리를 옮기지 않고 그 위에 보인다. 누르거나 포커스한 뒤 Enter를 누르면 대화 패널이 열린다. Unity 아이콘 바의 챗봇 버튼과 챗봇 서랍은 없앴다.
  - 패널은 아이콘 바 옆 서랍 자리에 다크 패널로 열리고, 머리에 안내원의 상반신이 보인다. 닫기 버튼이나 Esc로 닫는다. 다른 서랍(통합검색, 블록 탑재)을 열면 패널이 비켜 준다. 대화는 페이지에 남는다.
  - 로그인이 없거나 도우미 서버가 응답하지 않는 화면에서는 캐릭터가 나오지 않는다. 데스크톱 앱에는 챗봇이 없다.
- 캐릭터는 2D 원본 벡터다: 안전모, 형광 조끼, 작업복, 장갑, 안전화.
  - 머리·팔·다리가 따로 움직인다. 인사할 때 손을 흔들고, 이동할 때 팔로 가리키고, 말할 때 입이 움직이며, 도착하면 한 번 뛴다.
  - 표정(눈, 입, 눈썹)과 소품(조회할 때 태블릿)은 상태에 따라 바뀐다: 대기, 조회, 장면 검색, 카메라 이동, 도착, 후보 선택, 실패.
  - 계속 반복하는 움직임은 5초마다 한 번 눈을 깜박이는 것뿐이다. 동작 줄이기 설정에서는 모든 움직임을 끈다.
- 패널 위쪽 줄에는 이 브라우저의 재생 상태를 표시한다(날짜, 재생·일시정지, 야드 일정 또는 호선 탑재, 공용 계획 재생 동기화 여부). 그 아래에 조회 답변은 ERP 계획·실적과 공용 계획 재생 기준이며 이 화면의 재생과 별개라고 안내한다.
- 휴대폰과 낮은 가로 화면에서는 패널이 전체 화면으로 열린다. 카메라 이동을 시작하면 패널이 닫혀 장면이 보인다.
- 입력 중의 키(한글 IME 포함)는 Unity 단축키로 전달되지 않는다. 패널을 닫으면 포커스가 캔버스로 돌아간다.

## 화면의 안내원 (말풍선)

- 웹 트윈 화면 오른쪽 아래에 안내원 캐릭터가 서 있고 말풍선은 캐릭터 왼쪽에 뜬다. 누르거나 포커스 후 Enter를 누르면 대화 패널이 열린다. 패널이 열린 동안은 숨는다. 로딩 화면과 도우미를 쓸 수 없는 화면에서는 나오지 않는다.
- 캐릭터와 말풍선 버튼은 한 번 누르면 동작한다(누른 채로 손을 떼는 순간 실행, 키보드 Enter·Space 동일). 걷거나 비켜 서지 않는다.
- 말풍선으로 평소에 말을 건다. 무엇을 말할지는 장면 상태(`state`)로 정하고, 모델 답변은 쓰지 않는다.
  - 처음 인사.
  - 지금 골리앗이 드는 블록: “보러 가기”를 누르면 그 인양 현장으로 카메라를 옮긴다(`lift`). 이미 끝난 인양은 말하지 않는다.
  - 공용 재생 동기화, 호선 탑재 재생 진입, 재생 일시정지.
  - 사용 팁(최대 6번): “해 보기”나 “물어보기”를 누르면 그 질문을 보낸다.
- 말하는 간격:
  - 진행 중인 인양 소식은 직전 말풍선에서 20초 뒤부터, 다른 소식은 45초 뒤부터, 팁은 2분 뒤부터 말한다.
  - 사용자가 장면을 조작한 뒤 10초 동안은 말하지 않는다.
  - 말풍선은 7.5초(버튼이 있으면 11초) 뒤에 닫힌다. 마우스를 올리면 닫히지 않는다.
- 패널이 닫힌 상태에서 이동이나 조회 결과가 나오면, 안내원이 말풍선으로 알린다(휴대폰에서 이동할 때 등).
- “그만 말하기”를 누르면 평소 말풍선을 끈다. 설정은 이 브라우저에 저장된다. 패널 첫 화면의 “안내원 말풍선 다시 켜기”로 다시 켠다. 사용자 요청에 대한 결과는 꺼 두어도 알린다.

## 카메라 이동

- 명시적인 이동 요청에만 동작한다.
  - 예: “J안벽으로 이동해줘”, “SN2051-B101 블록 보여줘”, “골리앗 크레인에 줌인해줘”.
  - 사용자가 누른 버튼도 이동 요청으로 본다: 후보 버튼, 답변 출처의 “장면에서 … 보기”.
  - 계획·현황을 묻는 문장(“탑재 계획 보여줘”)은 조회로 처리한다.
- 이동 대상은 사용자가 입력한 명칭이나 ID다. 모델 답변의 좌표나 명령은 실행하지 않는다.
- 후보를 찾고 장면을 여는 동작은 통합검색과 같다. `YardObjectSearch.Find`로 후보를 찾고, `YardObjectSearch.Open`으로 카메라 프레이밍, 하이라이트, 상세 팝업을 연다.
  - 후보가 하나이거나 명칭·ID가 정확히 하나와 일치하면 바로 이동한다.
  - 후보가 여럿이면 선택 버튼을 보여 준다. 화면에 없는 후보는 “화면에 없음”과 그 이유를 표시한다.
- 성공은 카메라가 멈추고 대상이 화면 안에 들어온 뒤에만 표시한다. 6초 안에 대상이 화면에 들어오지 않으면 실패로 표시한다.
- 페이지를 새로 열지 않고, 재생 일자와 재생 상태도 바꾸지 않는다.

## 조회

- 탑재 계획(baseline·forecast)과 탑재 검사 실적(합격 등), 도크·안벽 배치, 크레인 계획 모의, 공용 트윈 재생은 `apps/assistant/server.py`의 읽기 전용 도구로 조회한다.
- 조회는 로그인한 사용자의 ERP 권한으로 한다. 재생 조작과 ERP 쓰기는 하지 않는다.

## 연동

| 역할 | 위치 |
| --- | --- |
| 패널, 캐릭터, 이동 요청 해석, 출처 | `apps/assistant/widget.js` (`data-context="twin"`) |
| 페이지와 장면 사이 요청 대기열 | `Runtime/Plugins/ShipyardWeb.jslib` (`ShipyardWeb_Assistant*`, `window.SiwsTwinScene`) |
| 장면 쪽 찾기·열기·도착 확인·재생 상태 | `Runtime/Dashboard/TwinAssistantBridge.cs` (WebGL에서 `DashboardShellView`가 추가) |
| 다른 서랍이 열릴 때 패널 접기 | `Runtime/Dashboard/DashboardShellView.cs` (`Open`) |
| 테스트 | `Tests/Editor/TwinAssistantBridgeTests.cs` |

- 요청은 JSON `{id, op, query|pick}`이다.
  - `find`: 후보 최대 6개를 돌려준다.
  - `open`: 마지막 후보 중 하나를 연다. 응답은 `moving`이 먼저 오고, 그다음 `arrived` 또는 `failed`가 온다.
  - `state`: 이 브라우저의 재생 상태를 돌려준다.
