# 오브젝트 이름 표시와 카메라 마우스 조작

## 오브젝트 이름 표시

- 3D 화면에서 블록, 건물·시설, 선박, 크레인, 운반 장비, 배경 차량·중장비 위에 마우스를 올리면 커서 근처에 이름을 표시한다. 클릭 없이 확인할 수 있어야 한다. 클릭하면 상세 팝업이 열린다([상세 팝업 명세](dashboard/object-detail.md)).
- 블록은 ID와 호선 번호, 건물은 ERP 시설명, 선박은 선명과 호선 번호를 표시한다. 이름이 비어 있으면 시설 ID 또는 호선 번호를 사용한다. 선박 위의 개별 블록이 선택되면 그 블록의 정보를 우선 표시한다.
- 화면에서 보이는 대상 중 커서 바로 아래 대상을 표시한다. 도로나 바다, 빈 화면, UI 위, 카메라 드래그 중에는 숨긴다. 툴팁은 화면 안에 유지하고 마우스 입력을 가로채지 않는다.
- 우선 `unity/Assets/ShipyardTwin/Runtime/Erection/ShipView.cs`와 `YardEnvironment.cs`에서 오브젝트 생성과 이름의 출처를 확인한다. 부모 오브젝트의 메타데이터를 자식 메시에서 찾을 수 있게 연결한다. 매 프레임 전체 씬을 순회하지 않고, 필요하면 단순한 선택 영역을 사용한다.
- 배경을 투과해 가려진 블록이 선택되지 않는지, 표시되지 않는 블록이 선택되지 않는지 확인한다.

## 카메라 조작

| 입력 | 동작 |
| --- | --- |
| 왼쪽·가운데 버튼 드래그 | 땅을 잡고 이동(커서 아래 지점이 커서를 따라감), 지연 없이 바로 반영 |
| 오른쪽 버튼 드래그, Alt/Ctrl+왼쪽 드래그 | 대상 주위로 시점 회전(픽셀 기준 감도) |
| 휠 | 커서 아래 지점 쪽으로 확대·축소. 브라우저의 큰 휠 값은 한 프레임 3단계까지만 반영 |
| 더블클릭 | 그 지점(오브젝트 또는 지면)을 중심으로 조금 확대 |
| WASD·화살표 / Q·E / +·- | 이동 / 회전 / 확대 |

- `unity/Assets/ShipyardTwin/Runtime/Interaction/OrbitCameraRig.cs`의 `HandleInput`에서 왼쪽과 오른쪽 버튼의 역할을 바꾼다. UI에서 시작한 드래그 차단, 휠, 단축키 등 기존 동작을 유지한다.
- `unity/Assets/ShipyardTwin/Authoring/Dashboard.uxml`, 루트 `README.md`, 카메라 클래스의 조작 안내를 새 입력과 맞춘다. 씬과 프리팹은 루트 `CLAUDE.md`의 기존 생성 절차를 따른다.

## 3인칭 보기

- 우측 상단 **걸어보기**를 누르면 현재 지도 화면 중심 근처의 보행 가능 지면에 캐릭터가 나타난다. 카메라가 캐릭터를 따라가며 뒤쪽 벽이 있으면 가까워진다. PC에서는 휠로 카메라 거리를 조절한다. **지도 시점** 버튼이나 Esc로 이전 시점에 돌아간다. 통합검색 결과를 선택하면 지도 카메라가 대상을 보여 준다.
- PC에서는 WASD나 화살표로 걷고, Shift를 함께 누르면 빠르게 이동한다. 오른쪽 마우스를 누른 채 끌면 시선을 돌린다. 터치에서는 화면 아래 조이스틱으로 이동하고, 3D 장면을 다른 손가락으로 끌어 시선을 돌린다.
- 3인칭 보행 속도는 **느리게(1 m/s) · 보통(1.8 m/s) · 빠르게(3.2 m/s)** 중에서 고른다. 이 선택은 다음에 3인칭 시점으로 돌아와도 같은 화면에서 유지된다. PC에서 Shift를 누르는 동안에는 임시로 더 빠르게 이동한다.
- 캐릭터는 실제 보행 방향으로 몸을 돌리고 보행 거리에 맞춰 발을 내디딘다. 로그인된 계정의 ERP 그룹을 읽어 일반 사원은 누더기 작업복 일꾼, 관리자(`ADMIN`)는 중인, 임원(`EXEC`, `EXECUTIVE` 또는 `임원`)은 은발 무림고수 외형을 사용한다. 미로그인, 조회 실패, 그 외 그룹에는 기본 일꾼 외형을 제공한다. 이 매핑은 야드의 외형에만 적용된다.
- 관리자 계정은 걸어보기에서 일꾼·중인·무림고수 외형 중 하나를 선택할 수 있다. 같은 화면에서 지도 시점으로 나갔다 돌아와도 선택을 유지한다.
- 보행은 야드 포장, 안벽, 도크 가장자리 같은 지면을 따른다. 건물이나 장비의 충돌체와 큰 단차, 물 경계에서는 걷기를 멈춘다. 카메라 모드를 바꿔도 일정 재생은 이어진다.
- 보행 중 크레인이나 중장비의 위험 구역에 들어가면 화면에 **위험 구역 진입**과 가장 가까운 장비 이름을 표시하고, 해당 구역을 바닥에 붉은 테두리와 사선으로 그린다. 겹친 구역은 모두 그리며 카드에 추가 건수가 나온다. 장비가 이동하면 범위도 따라간다. 구역을 벗어나거나 지도 시점으로 돌아가면 자동 표시가 사라진다.
- 레일 지브 크레인은 등록된 최대 작업반경과 여유를 사용한다. 제원이 없는 지브 크레인, 골리앗의 본체 기준 레일 작업 구역, 지게차·트랜스포터의 모델 크기 기반 반경은 추정으로 표시한다. 모든 경고는 시뮬레이션 표시다.

## 완료 기준

Unity Play Mode에서 블록·건물·선박의 이름을 각각 확인한다. 카메라를 드래그하거나 패널 위에 마우스를 올리면 이름 표시가 숨겨져야 한다. 왼쪽 이동, 오른쪽 회전, 가운데 이동, 휠, UI 위 카메라 입력 차단이 각각 동작하는지 확인한다.
