조선소 업무 적합성 점검

점검 항목확인 결과와 적용 조건
블록 건조 순서절단·가공, 블록 조립, 선행의장·PE, 탑재, 진수, 안벽 의장·시운전, 인도의 큰 흐름은 상선 신조 공법과 맞습니다. 조립과 선행의장은 블록별로 병행될 수 있으므로, 호선 전체에 한 줄짜리 순서를 강제하기보다는 블록과 작업 단위로 선후행을 관리하는 편이 적합합니다. 대선조선 건조 공정 · GAO 상선·함정 건조 공정 비교
계획 계층대일정의 도크·선석, 중일정의 블록·의장, 소일정의 사람과 설비가 수행할 작업을 구분한 구조는 적합합니다. 의장 선행 미완료 착수와 대일정 범위 초과는 조회 경고로 표시됩니다. 예를 들어 선행 의장 범위를 기공 후 14일까지로 잡는 규칙은 이 ERP의 설정된 판단 기준이므로 현장 기준과 맞춰야 합니다.
착수와 완료의 근거자재 출고, 이동 확정, 작업 검사, 탑재 합격을 서로 다른 기록으로 남깁니다. 주요 일정 실적도 별도로 등록합니다. 현장 시범 적용 시 담당자와 기록 시점, 검사 증빙의 원천을 확정할 필요가 있습니다.
자재 추적입고·출고·로트 관계를 관리하며 로트 미배정 출고는 추적 화면에 표시됩니다. 강재 추적이 필수인 현장은 미배정 상태를 언제까지 해소해야 하는지 종료 기준을 정해야 합니다.
설비·안벽 계획크레인 정격하중과 시간 중복, 선석 길이와 기간 중복을 확인할 수 있습니다. 화면의 일정 제안과 수치 점검만으로 실제 인양·안벽 이동 승인에 필요한 현장 검토가 완료되지는 않습니다.
의장 데이터 간 연결의장 작업의 진행률과 의장품의 입고·설치·검사는 별도 화면에서 기록합니다. 대일정 검토 때 두 화면의 결과를 함께 확인해야 합니다.

판정 — 상선 신조의 생산계획·실행·품질·물류를 연결하는 구조로 적합합니다. 특정 조선소의 운영 적합성은 실제 호선 한 척으로 일정 기준, 승인 절차, 자재 추적 마감과 설비 운용 조건을 대조한 뒤 판단할 수 있습니다.

실습에서 확인할 항목
  1. SN2036 준비 점검 — 중일정 · 선체에서 211P 블록 구성과 선행 블록을 확인합니다. 준비 현황의 보류 사유를 열고 조립·도면·자재·품질 중 어떤 근거가 필요한지 확인합니다.
  2. H101 자재 실행 — 실습 DB에서 MRP 부족 → 구매요청 → 발주 → 입고 검수 → 주간 지시 출고를 진행합니다. 합격 입고만 재고에 더해지고 출고는 해당 창고 잔량을 줄이는지 수불부에서 대조합니다.
  3. 탑재 분리 확인 — 블록 이동 확정 후 블록 위치가 바뀌는지 확인합니다. 탑재 합격 기록은 블록 위치와 별도로 관리되며 다음 블록의 선행 조건에서 확인합니다.
  4. 계획 예외 확인 — 같은 크레인의 중복 시간이나 같은 선석의 중복 기간을 입력해 저장 거절을 확인합니다. 의장 작업을 대일정 범위 밖에 잡고 점검 경고가 표시되는지 확인합니다.

이번 문서 검토에서는 메뉴 정의와 저장·판정 로직을 대조했고, SQLite 자동 테스트 23건이 통과했습니다. 위 실습 시나리오는 브라우저에서 현장 담당자가 수행할 확인 절차입니다.
