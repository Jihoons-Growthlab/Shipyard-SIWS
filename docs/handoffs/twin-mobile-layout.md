# 모바일 디지털 트윈 화면

- 요청은 휴대폰에서 트윈을 열면 비율이 깨져 사용하기 어려운 원인을 설명하는 것이었다. 이번 작업 기록의 상태는 코드 조사까지 완료다.
- 세로 화면 탑재 패널과 작은 화면의 접힌 일정표는 이미 구현돼 있다. 일정표의 접힘 상태는 첫 호선 선택 때 초기화한 뒤 유지된다.
- 모바일 잘림을 조사할 위치는 [WebGL 템플릿](../../apps/twin/unity/Assets/WebGLTemplates/Shipyard/index.html)의 상단 높이 고정값과 [대시보드 스타일](../../apps/twin/unity/Assets/ShipyardTwin/Authoring/Dashboard.uss)의 한 줄 재생 버튼 배치다. 코드상 후보이며 실기기 원인은 확인 전이다.
- 다음 검증은 iPhone Safari의 세로·가로 회전과 주소창 전환에서 상단 메뉴 실제 높이, 3D 화면 경계, 하단 일정 버튼의 잘림을 재현하는 것이다. 수정 시 WebGL을 빌드하고 같은 조건에서 전후를 비교한다.
